🛒 ClipKart E-Commerce Sales Analytics Dashboard

An interactive Power BI sales analytics dashboard built to analyze ClipKart e-commerce performance across revenue, orders, quantity sold, products, categories, and cities.

The project focuses on transforming raw e-commerce transaction data into clear, interactive business insights using Power BI.

📊 Project Overview

The ClipKart dashboard provides a single-page view of key sales performance metrics and allows users to explore the data using interactive filters.

Key Business Questions

How much total revenue was generated?

How many orders were placed?

How many products were sold?

Which categories generate the most revenue?

Which products are the top revenue contributors?

Which cities perform best?

Is there a relationship between product price and revenue?

How do sales metrics change when different categories, cities, products, or dates are selected?

📌 Dashboard KPIs

The dashboard highlights the following key performance indicators:

💰 Total Revenue

Measures the overall revenue generated from all orders.

🛒 Total Orders

Counts the number of unique orders.

📦 Total Quantity Sold

Shows the total number of units sold.

💵 Average Order Value

Calculated as:

Average Order Value = Total Revenue / Total Orders

For the supplied dataset:

Average Order Value = 6,157.48

📐 Example DAX Measures

Total Revenue

Total Revenue =
SUM('ClipKart'[Revenue])

Total Orders

Total Orders =
DISTINCTCOUNT('ClipKart'[OrderID])

Total Quantity

Total Quantity =
SUM('ClipKart'[Quantity])

Average Order Value

Average Order Value =
DIVIDE([Total Revenue], [Total Orders])

Replace 'ClipKart' with the actual table name in Power BI if your model uses a different name.
